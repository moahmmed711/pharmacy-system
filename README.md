# نظام صيدلية الشفاء الذكي المتكامل (Al-Shifa Smart Pharmacy POS System)

نظام صيدلية متكامل، احترافي، وسريع مبني باستخدام **HTML5, CSS3, JavaScript (Vanilla)** بدون أي أطر عمل خارجية ثقيلة، ويعمل بشكل كامل ومستقل محلياً عبر تقنية **LocalStorage**.

---

## 🌟 الميزات الرئيسية للنظام

1. **نقطة البيع وسلة المبيعات (POS & Cart)**:
   - واجهة كاشير شاشة مقسومة (Split Screen): الأدوية والكتالوج يميناً، وسلة المبيعات الفورية يساراً.
   - دعم قارئ الباركود السريع (Barcode Scanner) والإضافة التلقائية بمجرد الضغط على Enter.
   - سلة مبيعات تفاعلية تتيح زيادة وإنقاص الكميات مع منع تجاوز الرصيد المتاح.
   - حساب تلقائي وفوري للمجموع الفرعي، الخصومات، وضريبة القيمة المضافة (15% VAT).
   - نافذة دفع سريع (نقداً، بطاقة/شبكة، آجل) مع حاسبة للمتبقي للعميل وأزرار مبالغ نقدية جاهزة.
   - مؤثرات صوتية تحاكي أجهزة الكاشير الواقعية (صوت بيب الباركود ورنين إتمام البيع عبر Web Audio API بدون ملفات خارجية).

2. **إدارة المخزون والأدوية (Inventory Management)**:
   - بطاقة دواء مفصلة: (الاسم التجاري، الاسم العلمي، الباركود، التصنيف، الشكل الصيدلاني، سعر الشراء، سعر البيع، الرصيد، حد الطلب، تاريخ الصلاحية، موقع الرف، الشركة المصنعة).
   - تنبيهات ملونة ذكية لنواقص المخزون والأدوية المنتهية أو القريبة من الانتهاء (خلال 60 يوماً).
   - تصدير كامل بيانات المخزون والأدوية إلى ملف إكسل بصيغة CSV بنقرة واحدة.

3. **إدارة المشتريات والتوريد (Purchases & Supplies)**:
   - تسجيل فواتير التوريد من شركات الأدوية والمستودعات.
   - جدول ديناميكي لإضافة بنود الأدوية والكميات وسعر الشراء وتاريخ الصلاحية.
   - التحديث التلقائي الفوري لرصيد الأدوية في المخزون وتحديث أسعار الشراء والبيع عند حفظ الفاتورة.

4. **طباعة الفواتير وأرشيف المبيعات (Invoices & Printing)**:
   - أرشيف كامل لكافة فواتير المبيعات مع إمكانية البحث بالرقم، اسم العميل، أو التاريخ.
   - **نمطان احترافيان للطباعة**:
     - **فاتورة كاشير حرارية (80mm Thermal Receipt)**: مصممة خصيصاً لطابعات الإيصالات الحرارية مع رمز QR، ورقم ضريبي، وشروط الاسترجاع.
     - **فاتورة ضريبية رسمية (A4 Tax Invoice)**: تنسيق رسمي للشركات والجهات يتضمن الترويسة الطبية، بيانات العميل، والجدول التفصيلي والضريبة.
   - دعم كامل لإرجاع وإلغاء الفواتير مع إعادة الكميات المباعة تلقائياً إلى رصيد المخزون.

5. **لوحة المؤشرات والتقارير (Analytics & Reports)**:
   - بطاقات إحصائية فورية: مبيعات اليوم، مبيعات الشهر، تقدير صافي الأرباح، عدد نواقص المخزون، والقيمة الإجمالية للمخزون (بسعر البيع والتكلفة).
   - تحليل أكثر 5 أدوية مبيعاً بنسب مئوية وأشرطة تفاعلية.
   - سجل مباشر لآخر العمليات وتنبيهات النواقص العاجلة.

6. **التخزين المحلي والنسخ الاحتياطي (Storage & Backup)**:
   - حفظ فوري ودائم على `localStorage` في متصفحك دون الحاجة لإنترنت أو قاعدة بيانات خارجية.
   - تصدير واستيراد النسخ الاحتياطية بصيغة JSON لنقل البيانات بين الأجهزة بسهولة.
   - زر لإعادة تعيين واستعادة البيانات التجريبية الأولية في أي وقت.

## 🚀 طرق تشغيل النظام

### الطريقة الأولى: التشغيل المباشر عبر المتصفح (الأسهل والأسرع)
- ما عليك سوى التوجه إلى مجلد `pharmacy-system/` والنقر المزدوج على ملف `index.html` ليفتح فوراً في أي متصفح (Chrome, Edge, Firefox, Safari).

### الطريقة الثانية: التشغيل عبر ملف التشغيل السريع (ويندوز)
- انقر نقراً مزدوجاً على ملف `start.bat`، وسيقوم بتشغيل الخادم المحلي وفتح النظام تلقائياً في متصفحك على:
  ```
  http://localhost:8088
  ```

### الطريقة الثالثة: التشغيل عبر سطر الأوامر (Node.js)
```bash
cd pharmacy-system
node server.js
```
ثم افتح الرابط: `http://localhost:8088`

## ⌨️ اختصارات لوحة المفاتيح السريعة

- **F2**: الانتقال الفوري لشاشة نقطة البيع (الكاشير).
- **F3**: التركيز السريع على حقل البحث عن الأدوية وقارئ الباركود.
- **F4**: الانتقال الفوري لشاشة المخزون والأدوية.
- **F9**: فتح نافذة الدفع السريع وإتمام البيع.
- **Escape**: إغلاق أي نافذة منبثقة مفتوحة.

## 📁 هيكل ملفات المشروع

```
pharmacy-system/
├── index.html              # واجهة النظام المتكاملة والتبويبات والنوافذ المنبثقة
├── server.js               # خادم محلي خفيف مبني بـ Node.js بدون مكتبات خارجية
├── start.bat               # مشغل سريع بنقرة واحدة لأنظمة ويندوز
├── README.md               # دليل التشغيل والميزات
├── css/
│   ├── styles.css          # التصميم الطبي العصري الفاخر (RTL والزجاجي)
│   └── print.css           # أنماط الطباعة المخصصة للفواتير (حراري 80 مم و A4)
└── js/
    ├── storage.js          # محرك التخزين المحلي، البيانات الافتراضية، والنسخ الاحتياطي
    ├── pos.js              # منطق الكاشير وسلة المبيعات وقارئ الباركود والدفع
    ├── inventory.js        # إدارة المخزون وبطاقة الدواء وفحص الصلاحيات
    ├── purchases.js        # فواتير الشراء والتوريد وتحديث الأرصدة
    ├── invoices.js         # أرشيف الفواتير ومعاينة وطباعة الفاتورة واسترجاعها
    ├── reports.js          # مؤشرات الأداء، حساب الأرباح، والأدوية الأكثر طلباً
    └── app.js              # التهيئة العامة، التنقل، والمؤثرات الصوتية للكاشير
```
